## Wie es funktioniert

- Jeden Morgen fragt eine GitHub Action die öffentlichen Job-APIs von über 210 Unternehmen ab. Keine Job-Portale, kein Scraping von StepStone oder Indeed.
- Behalten werden Stellen in Deutschland, Österreich und der Schweiz, deren Titel eine Einstiegsrolle ist (Werkstudent, Praktikum/Intern, Absolvent/Graduate, Junior/Trainee).
- Fällt eine Quelle aus oder schrumpft die Liste plötzlich, wird nichts veröffentlicht und der Lauf schlägt sichtbar fehl, statt eine halbe Liste zu zeigen.
- Die Daten gibt es als [jobs.json](jobs.json) und [jobs.csv](jobs.csv). Frei nutzbar, ein Link zurück freut uns.
